## 5. WAF 行為

以 `curl -A "Mozilla/5.0"` 存取任何路徑（含 `robots.txt`、`sitemap.xml`）：

```
HTTP 406 Not Acceptable
<h1>Not Acceptable!</h1>
<p>...This error was generated by Mod_Security.</p>
```

改用 WebFetch（一般瀏覽器 UA）則正常回應 200。

**推論**：Mod_Security 以 User-Agent 為判斷依據，極可能同時擋下 GPTBot、ClaudeBot、PerplexityBot、OAI-SearchBot 等 AI 爬蟲。

**待驗證**（需主機端配合）：以各 AI 爬蟲的實際 UA 字串逐一測試回應碼。這是 GEO 策略的前提條件，見 [../03-seo-geo.md](../03-seo-geo.md) §1。
